# إعداد FAJR

## المتطلبات
- Flutter stable متوافق مع قيد Dart في `pubspec.yaml`.
- GitHub Actions مفعّل للمستودع.
- لا تحتاج أسرارًا لبناء APK التجريبي في المرحلة الحالية.

## Android
يولّد Workflow `build-android.yml` ملفات منصة Android في مساحة العمل عند غيابها. إذا احتجنا إعدادات دائمة مثل اسم الحزمة النهائي أو الأذونات أو روابط OAuth أو Firebase، راجع الملفات المولدة ثم احفظ التعديلات المقصودة في المستودع بدل الاعتماد على توليد مؤقت فقط.

## Firebase والمكالمات
لم تُهيأ الخدمات السحابية ومزود المكالمات ضمن هذا الأساس. لا تضف ملفات أسرار إلى Git. عند تنفيذ التكامل، استخدم إعدادات خارج المستودع ووثّق كل متغير مطلوب.
