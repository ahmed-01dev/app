# فَجْر — FAJR

تطبيق Flutter عربي باتجاه RTL، بهوية إسلامية كحلية وزمردية وذهبية. هذه نسخة تأسيسية قابلة للتطوير وليست إصدار إنتاج مكتملًا.

## الموجود حاليًا
- هيكل Flutter أساسي وشاشة رئيسية.
- أذكار صباح أولية مع بيانات مصدر لكل عنصر.
- حساب محلي لمواقيت الصلاة بعد اختيار مدينة من القائمة المتاحة.
- شاشة بدء تشغيل تتعامل مع وضع محلي عند عدم إعداد الخدمات السحابية.
- اختبارات أولية لمعالجة الأخطاء وبدء التشغيل.
- GitHub Actions للتحليل والاختبارات وبناء APK تجريبي.

## إنشاء Android وقت البناء
إذا كان مجلد `android/` غير موجود، يقوم Workflow `build-android.yml` بمحاولة إنشاء ملفات منصة Android داخل مساحة عمل البناء باستخدام:

```bash
flutter create --platforms=android --org com.fajr --project-name fajr .
```

الملفات الناتجة في GitHub Actions لا تُحفظ تلقائيًا في المستودع. هذا يسمح بتجربة البناء دون رفع مجلد Android يدويًا، لكنه لا يغني عن حفظ أي إعدادات Android مخصصة داخل المستودع عند الحاجة.

## تنزيل APK
1. افتح تبويب **Actions**.
2. اختر **build-android** ثم **Run workflow**، أو افتح تشغيلًا بدأ بعد تحديث `main`.
3. بعد نجاح التشغيل، نزّل artifact باسم `fajr-debug-apk`.

هذا APK للتجربة، وليس نسخة إنتاج موقعة للنشر في Google Play.

## النواقص المعروفة
- تسجيل الدخول والخدمات السحابية تحتاج إعداد Firebase واختبارات تكامل.
- المكالمات الصوتية والأصدقاء والفرق والتصنيفات غير مكتملة.
- قائمة المدن ومحتوى الأذكار يحتاجان مراجعة وتوسيعًا.
- القرآن الكامل والقبلة والتقويم الهجري لم تكتمل.
- لا تعتبر النسخة جاهزة للنشر قبل إكمال الأمان والخصوصية والاختبارات على أجهزة فعلية.
